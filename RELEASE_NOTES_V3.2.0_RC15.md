# Spa Control v3.2.0 RC15

Bugfix and translation release based on RC14.

## Fixed
- Weather and dynamic labels now also use top-level translations.
- Planner Add Schedule button and schedule management restored.
- Diagnostics OTA/MQTT status, live log labels, buttons and common log messages translated.
- Live-log toolbar stays inside the card on phone and desktop.
- Maintenance alerts and save/error feedback follow the selected language.

No existing spa, MQTT, planner backend or maintenance functionality was removed.
