# Security policy

## Supported version

Security fixes are applied to the latest stable release where practical.

## Reporting a vulnerability

Do not publish credentials, private network details or a working exploit in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile, then provide:

- affected version;
- reproduction steps;
- impact;
- suggested mitigation, if known.

## Operational safety

- Never expose the controller directly to the public internet.
- Use a trusted local network and strong Wi-Fi credentials.
- Use MQTT authentication when MQTT is enabled.
- Treat OTA access and the local web interface as administrative access.
- Disconnect mains power before changing wiring or opening the spa controller.
