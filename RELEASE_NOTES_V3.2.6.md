# Spa Control v3.2.6

ESP8266 / Arduino / PlatformIO release for Bestway Lay-Z-Spa control.

## Changes since v3.2.1

- Improved WiFi setup feedback and recovery.
- Added controlled restart after first successful WiFi provisioning.
- Improved readability of scanned WiFi networks in light mode.
- Added connector hardware test with green/red result indicators.
- Connector test now pauses normal CIO/DSP communication before the bench test and restores communication afterwards.
- Added and updated NL / EN / DE / FR translations for the new functions.
- Updated firmware, web interface and PWA cache version to v3.2.6.

## Upgrade

For a complete update, install both the matching firmware image and LittleFS image.
