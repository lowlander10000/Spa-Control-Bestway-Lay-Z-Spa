# Contributing

Thank you for helping improve Spa Control.

## Before opening an issue

- Confirm the problem still exists on the latest release.
- State your spa model, connector/driver type and ESP8266 board.
- Include the Spa Control version and relevant serial-log lines.
- Remove Wi-Fi passwords, MQTT passwords, IP addresses and other private data.
- Describe the expected and actual behavior and the exact steps needed to reproduce it.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep each pull request limited to one feature or bug fix.
3. Preserve compatibility with the `nodemcuv2` PlatformIO environment.
4. Do not commit `.pio`, IDE caches, firmware binaries, secrets or local settings.
5. Test both firmware upload and LittleFS upload when web files change.
6. Verify mobile and desktop layouts when changing CSS or HTML.
7. Update documentation and `CHANGELOG.md` where appropriate.

By contributing, you agree that your contribution is distributed under GPL-3.0 as part of this project.
