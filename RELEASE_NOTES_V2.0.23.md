# v2.0.23 - Compacte weerkaart

- Compacte weerkaart toegevoegd aan het dashboard.
- Plaats, land, update-interval en aan/uit staan onder Instellingen > Regio & Tijd.
- Locatiezoekfunctie via Open-Meteo geocoding.
- Actueel weer via Open-Meteo zonder API-sleutel.
- Weerkaart kan worden verborgen en versleept zoals de andere dashboardkaarten.
- Vertalingen toegevoegd voor Nederlands, Engels, Duits en Frans.
- Alleen LittleFS-bestanden gewijzigd.
